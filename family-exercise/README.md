# 一起動｜可安裝手機版

這是獨立的靜態 PWA。開啟 https://twkelly69.github.io/family-exercise/ ，即可在手機瀏覽器加入主畫面；初次載入後，抽籤、說明與打卡可離線使用。YouTube 搜尋連結需要網路。

資料以瀏覽器 localStorage 留在該裝置，沒有帳號、家庭跨裝置同步或雲端資料庫。手機可能清除網站資料，請定期在「手機安裝與資料備份」匯出 JSON。匯入會取代目前這台裝置的家人與紀錄。

五個年齡組共用 17 支運動籤，各自抽選適合動作；每人每天固定一籤，隔天避開前一天動作。三段可分開完成。

這是公開試用版。若要向其他家庭販售由各買家自行管理、可跨裝置共用資料的工作包，請使用獨立交付流程，不要把付費包原始檔放在公開 GitHub 倉庫。
